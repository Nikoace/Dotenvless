## DPAPI 安全边界

根据 [Microsoft CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)，默认保护通常绑定相同用户凭据和机器；`CRYPTPROTECT_LOCAL_MACHINE` 放宽为机器范围，本项目禁止使用。调用采用无 UI 模式，释放 Windows 分配的输出缓冲。

同用户进程可能解密，因此 V0.1 不能实现「同身份 Agent 可以启动应用但绝不能接触 Secret」。该能力需要未来独立权限边界。子进程继承 Secret 后也可主动输出、联网或启动后代，不属于 Vault 加密能够阻止的行为。

跨账户测试只覆盖普通不同账户，不承诺防御管理员、域恢复机制或完全受控的宿主系统。
