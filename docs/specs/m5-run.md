# M5：子进程环境注入

已确认：自动支持 .cmd/.bat 的常见参数，无法可靠传递时明确拒绝；不为「全部 shell 语法」提供隐式保证。

- 命令必须形如 dvl run -- COMMAND [ARG...]。解析器不回显非法参数。
- 可执行文件按原进程 PATH/PATHEXT 解析；注入的 PATH 不改变本次要启动的命令选择。显式相对路径可用。
- 普通程序直接 exec，不调用 shell，不把 Secret 放在命令行中。
- .cmd/.bat 通过系统 cmd.exe /d /v:off /s /c 启动。批处理命令路径/参数拒绝控制字符、双引号、%、!、^、&、|、<、>；批处理参数还拒绝末尾反斜杠，避免 shell 与目标程序的两种引号规则产生歧义。支持空参数、空格、Unicode 和括号。
- ./gradlew 优先选择旁边存在的 gradlew.bat；明确的其他命令不做猜测性重写。
- 继承工作目录和三条标准流。环境按 Windows 不区分大小写合并，项目值覆盖父进程同名值，保留 Windows 驱动器环境项。父进程环境不变。
- 返回目标进程退出码，启动错误返回操作失败且不输出命令参数。目标 stdout/stderr 原样传递，因此目标主动输出 Secret 不属于 dvl 的输出隐藏承诺。
- Ctrl+C 由共享控制台送达子进程，dvl 自身等待目标退出并返回其状态；不创建脱离控制台的后台进程，不保证恶意程序及所有后代强制回收。
- 不创建任何 .env 或明文临时文件。

验收：真实子进程检查假 Secret/继承变量/参数/cwd/stdin，正常及非零退出；父环境不变；批处理安全参数成功且危险参数在启动前被拒绝；Python、Node、CMD、PowerShell、npm、Gradle 各自记录实测或缺少环境。
