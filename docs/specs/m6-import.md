# M6：dotenv 导入

已确认：同名键默认导致整次导入失败；显式 --overwrite 才覆盖，绝不删除源文件。

命令支持 dvl import FILE、dvl import --overwrite FILE、dvl import FILE --overwrite。

语法：UTF-8（可有 BOM）、LF/CRLF、空行、# 注释、可选 export、等号两边空白、空值、单/双引号、多行引号值。双引号识别反斜杠、双引号、n/r/t 转义；单引号内容逐字保留。未加引号的 # 仅在开头或前有空白时作为注释。尾随无关内容、未知转义、未闭合引号、非法键和大小写重复键报行号错误；错误不回显该行。

不插值：$VAR、${VAR}、$(command) 均作为字面内容保存，不执行命令。单个源文件至多 1 MiB，单值沿用 32 KiB/UTF-8/无 NUL 限制。

读取和解析全部成功、所有键通过校验后才进入 Vault 事务；先检查全部冲突，再加密每个值。任一步失败不修改磁盘旧 Vault。成功只输出总数和排序键名。无变量文件成功返回 0，不改变 Vault。

验收：语法正反例、字面值不展开、大小写冲突、解析/加密/写入失败的整批原子性、--overwrite 明确覆盖、源文件保留、输出无 value。
